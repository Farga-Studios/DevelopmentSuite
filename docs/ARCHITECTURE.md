# Architecture 0.1.0
Independent applications under Farga Studios, intended for MIT open-source publication after review. Each application owns its source, releases and distribution. Private game adapters remain separate. Shared libraries are versioned independently; no dependency on SEALSWORN engine in generic tools. SpriteLab first, EntityLab, TileLab, DungeonLab, BalanceLab, TestLab, AILab, AssetLab, AudioLab, NarrativeLab. DungeonLab must use the exact versioned game generator and catalog via an adapter; TileLab supports TMJ and special rooms, sockets, collision and spawn validation.
UI: shared dark palette #171B22 / #202630 / #11151C, borders #353E4C, accent #42678D, close hover #C42B36 and pressed #A91E2C; keyboard focus, native file picker, safe modal cancellation. Localization: ES/EN stable resource keys and placeholder parity, system culture fallback, no user-content or schema translation. Settings: atomic local writes, separate project and installation directories. Diagnostics: bounded, no credentials or personal data. Extract each module only after acceptance and keep consumers pinned. No premature empty libraries.
