# Distribution contract
Each public application repository under Farga-Studios owns its release assets, with tags vX.Y.Z. SpriteLab stable metadata: https://raw.githubusercontent.com/Farga-Studios/SpriteLab/main/channels/stable/update.json and adjacent update.json.sig. Exact bytes signed RSA SHA256 PKCS#1; pinned public key in client; private key offline. Manifest product, channel, version, file_name, bytes, sha256, notes. Installer at https://github.com/Farga-Studios/SpriteLab/releases/download/vX.Y.Z/SpriteLab-X.Y.Z-win-x64-setup.exe. Publish assets first, then atomically commit signed index pair. Do not publish unsigned indexes. No credentials in public repositories. No release without approval. Authenticode separate. Verified installer handoff exists as a candidate; rollback and Windows acceptance remain pending. MarkdownLab retains its existing release protocol for compatibility. The former central downloads repository is retained until dependency and legacy-client checks are complete.
