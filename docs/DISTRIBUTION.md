# Distribution contract
Public repository Sealsworn/DevelopmentSuite-Downloads. Per-product tags spritelab-vX.Y.Z, entitylab-vX.Y.Z, etc. Never use repository-wide latest release to identify a tool update. Stable index: https://raw.githubusercontent.com/Sealsworn/DevelopmentSuite-Downloads/main/channels/spritelab/stable/update.json and adjacent update.json.sig. Exact bytes signed RSA SHA256 PKCS#1; pinned public key in client; private key offline. Manifest product, channel, version, file_name, bytes, sha256, notes. Installer at releases/download/spritelab-vX.Y.Z/SpriteLab-X.Y.Z-win-x64-setup.exe. Publish assets first, then atomically commit signed index pair. Do not publish an unsigned index. Installer/portable have independent checksums. No source or credentials in public repo. No release without approval. Signed manifest authenticates package hash; Authenticode separate. Automatic handoff/restart and rollback are not yet implemented. Validate upgrades, failure modes and clean Windows install before acceptance.
